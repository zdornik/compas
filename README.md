# Компас

Приложение для пациента и врача: дневник настроения и сна, терапия и отметки приёма, опросники, переписка, приёмы и медицинский справочник. React 19, Node.js, PostgreSQL 17.

## Где что находится

| Каталог | Назначение |
| --- | --- |
| [`mvp`](mvp/README.md) | Основное приложение, API, схема БД, тесты и инструменты запуска |
| [`docs`](docs/README.md) | Навигация по технической документации |

Основной интерфейс использует анимацию p1. Параметр `?background=static` возвращает сохранённый статичный фон. В репозитории поддерживается одна основная версия интерфейса.

## Быстрый запуск для знакомства

Требуются Node.js 22.13+ и PostgreSQL **17** с серверными утилитами. Для CI используется Node.js 24.

```sh
cd mvp
npm ci
npm run build
npm run presentation:prepare
npm run presentation:start
npm run presentation:check
```

Приложение откроется на [127.0.0.1:4176](http://127.0.0.1:4176/). Стенд создаёт отдельную БД с вымышленными пациентом и врачом. Логины и случайный пароль находятся в локальном `mvp/qa/presentation/accounts.json`. Повторный запуск сохраняет данные. Подробное руководство: [запуск для коллеги](mvp/PRESENTATION-HANDOFF.md).

Для Docker без загрузки большого справочника: `npm run docker:up -- --skip-reference` из `mvp`. Адрес — [127.0.0.1:4174](http://127.0.0.1:4174/). Эта команда создаёт обычное окружение; для отдельного просмотра используйте presentation-режим.

## База данных и справочник

В Git включены схема, миграции и код импорта. Персональные БД, ключи и пароли не публикуются: они создаются для каждого окружения отдельно. Для передачи публичного справочника используется снимок только схемы `knowledge`, без пользовательских данных, из отдельного [Release справочника](https://github.com/zdornik/compas/releases/tag/reference-db-2026-10-19), а не россыпь исходных выгрузок. Он требует доступа и значительного свободного места; быстрый запуск выше его не скачивает.

Новый демонстрационный стенд не содержит полного корпуса. Можно отдельно импортировать проверенный небольшой публичный образец. Состав снимка, версии и восстановление описаны в [инструкции БД](mvp/database/README.md), ограничения источников — в [справочнике](mvp/KNOWLEDGE.md).

## Разработка и ограничения

[Участие в разработке](CONTRIBUTING.md) · [состояние подготовки](RELEASE.md) · [архитектура](mvp/ARCHITECTURE.md) · [безопасность](mvp/SECURITY.md).

Исследовательское приложение: используйте вымышленные данные. Обработка текста работает как явная локальная заглушка; push/email, восстановление пароля и подтверждение квалификации врача не подключены. Сохранение записей и взаимодействие кабинетов работают через сервер и БД. Отсутствие предупреждения в справочнике не подтверждает безопасность лечения.
