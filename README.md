# Компас

Локальное приложение пациента и врача. Основной проект и инструкция запуска находятся в [mvp](mvp/README.md).

В репозитории есть схема и автоматическое восстановление **готовой PostgreSQL-базы справочника**. Сам снимок БД, включая PDF и разметку, размещён в [приватном релизе GitHub](https://github.com/zdornik/compas/releases/tag/reference-db-2026-10-19). Это дамп импортированной базы, а не набор исходных Excel/JSON.

После установки Docker, Node.js и GitHub CLI и входа через `gh auth login`:

```sh
cd mvp
npm run docker:up
```

При первом запуске база загрузится и восстановится автоматически. Нужен доступ к этому приватному репозиторию и достаточно места для базы; ориентир — 40 ГБ свободного пространства. Адрес приложения: http://127.0.0.1:4174/.
