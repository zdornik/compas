# Компас · MVP пациента и врача

Актуально на 24 октября 2026. React 19.2 / Node / PostgreSQL 17. Использовать вымышленные данные.

## Возможности

| Возможность | Текущее состояние |
| --- | --- |
| Аккаунты пациента/врача | Вход по паролю, отдельные ролевые cookie; email/квалификация не проверяются, recovery/MFA отсутствуют |
| Дневник | Настроение, сон, PHQ-9/GAD-7, длинные заметки, страницы истории и выбранные периоды; серверная валидация/пересчёт |
| Подключение врача | Код → запрос врача → подтверждение пациентом; отзыв доступа |
| Заметки врача | Отдельные согласия, шифрованные версии, очередь, список/исходник, уведомления и подтверждение просмотра |
| Анализ текста | **Явная локальная заглушка**. Внешней нейросети и медицинской классификации нет |
| Приёмы | Врач назначает, пациент запрашивает; подтверждение/отклонение, отмена и защита пересечений в БД |
| Лечение и общение | Медицинский профиль, ручные схемы, доставка назначения при разрешённой связи, шифрованный чат |
| Справочник | Реально загруженные источники; текст по мере чтения, оригиналы, хеши и происхождение |
| Уведомления | В открытом приложении. Push/email, дежурная служба и создание видеовстреч не реализованы |

Отсутствие взаимодействия в источнике не доказывает безопасность назначения. Справочник исследовательский; права коммерческого использования и медицинское применение требуют отдельной проверки.

## Изолированный стенд для презентации

Инструкция — [PRESENTATION.md](PRESENTATION.md). Нужны Node 22+ и PostgreSQL **17** с initdb/pg_ctl/psql; Docker этому режиму не нужен.

```sh
npm ci
npm run build
npm run presentation:prepare
npm run presentation:start
npm run presentation:check
```

Адрес — http://127.0.0.1:4176/. Отдельные кластер, роли, ключи, cookie и вымышленные аккаунты. Учётные данные — в игнорируемом `qa/presentation/accounts.json`. Проверка готовности сохраняет тестовую заметку и ждёт результата worker, а не только HTTP health.

Справочник нового стенда пуст. Имеющийся локальный официальный образец КР переносится отдельно: `npm run presentation:reference -- --from-local-reference`. Полный корпус не скачивается. Подготовленный небольшой reference-пакет можно импортировать повторно без основной БД командой `npm run presentation:reference`.

## Основной Docker-режим

Нужны Docker Compose и Node. `npm run docker:up` создаёт секреты, применяет миграции, по умолчанию восстанавливает справочный снимок и запускает web/worker. Снимок около **15,9 ГБ**, нужны дополнительное место и доступ к приватному Release. Полная загрузка сейчас отложена пользователем.

Для разработки без корпуса:

```sh
npm run docker:up -- --skip-reference
```

Основной адрес — http://127.0.0.1:4174/. Пустой справочник ограничивает поиск препаратов, но не дневник/заметки/приёмы. `npm run dev` запускает Vite-интерфейс, а не полный PostgreSQL API.

## Данные и проверки

Содержимое медицинских записей шифруется AES-256-GCM. Расшифровывают сервер и разрешённый worker, затем данные получает интерфейс. Это не end-to-end; даты/связи/статусы и signal_level — открытые метаданные БД. Ключи — отдельно. Черновики в памяти React, персональные API no-store; постоянного браузерного хранения медицинских данных нет.

Публичные PDF/изображения лежат в файловом архиве с совместимостью старого bytea. Новый export v2 включает БД и объекты; опубликованный манифест пока v1. Справочный экспорт не является бэкапом персональных данных. См. [REFERENCE-FILES.md](REFERENCE-FILES.md), [database/README.md](database/README.md).

```sh
npm run build
npm test
python3 -m unittest discover -s tests -p 'test_*.py'
npm run test:integration
npx playwright install --with-deps chromium # на macOS можно использовать уже установленный Chrome
npm run test:browser
```

Интеграционная команда требует PostgreSQL и файлы admin/app/worker паролей (по умолчанию `.local-secrets`). Создаёт свою `compass_journal_qa_<random>`, новый ключ, применяет миграции и удаляет только эту БД после проверки. Существующие роли сначала проверяются; неверные credentials не меняют их пароли. `PG_BIN` задаёт каталог утилит, `ADMIN_DB_PASSWORD` может заменить файл для CI. Браузерная команда также создаёт свою БД и браузерный профиль: проверяет реальный UI двух ролей, worker/alert, черновик, отзыв и короткий сетевой замер. Результат — `qa/browser/report.json` и screenshots; сырые личные API-ответы в отчёт не пишутся. API истории и ограничения — [HISTORY.md](HISTORY.md). Workflow находится в `.github/workflows/checks.yml` корня репозитория.

Замороженное внешнее демо эти команды не обновляют. Его старая конфигурация не соответствует текущей схеме; новая публикация требует отдельной подготовки. Sites-упаковка сохраняет статический интерфейс, но сама не переносит PostgreSQL API.

## Бэкап и репетиция

`npm run presentation:backup` создаёт зашифрованный комплект небольшого стенда, `npm run presentation:restore-check` проверяет его в новой БД. Состав, независимый ключ и ограничения — [BACKUP.md](BACKUP.md). Не заменяет вынос бэкапа с компьютера.

`npm run test:rehearsal` запускает 20-минутный локальный браузерный прогон. `npm run presentation:video` записывает синтетические кабинеты и создаёт офлайн-плеер `qa/video/index.html`; для записи нужен `npx playwright install ffmpeg`. Обе команды создают/удаляют собственные QA-БД. Сводный результат подготовки — [SESSION-REPORT-2026-10-24.md](SESSION-REPORT-2026-10-24.md).
