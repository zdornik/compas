# Разработка macOS-комплекта

Пакет содержит готовую сборку и исходники одного приложения Компас. Для просмотра начните с `READ-ME-FIRST.md`; аккаунты описаны в `DEMO-ACCOUNTS.md`.

## Запуск и остановка

Из корня распакованного пакета:

```sh
bash START.command
bash CHECK.command
bash STOP.command
```

Нужны Node.js 22+ и PostgreSQL 17. Лаунчер обнаружит их локально либо установит через имеющийся Homebrew. PostgreSQL запускается отдельным процессом для этого комплекта; `brew services` не требуется. Проверка готовности должна вернуть `ready:true`.

При конфликте портов 4176/55434 остановите другую копию её штатной командой. Повторный запуск сохраняет аккаунты, ключи и записи. Сброс, изменение имени БД и удаление `qa/presentation` для устранения ошибки не нужны.

## Структура и сборка

- `src/` — интерфейс и общие расчёты; `public/` — ресурсы.
- `server/` — API, авторизация, доступ к данным и обработка записей.
- `docker/migrations/` — последовательные идемпотентные миграции.
- `scripts/`, `tests/` — запуск, сборка и проверки.
- `dist/client/` — результат сборки, не место для ручных изменений.

Для разработки установите полный набор npm-зависимостей:

```sh
npm ci
npm test
npm run build
npm run check:release -- --build
```

После изменения backend или сборки выполните STOP и START. Обычный просмотр использует включённые runtime-пакеты и не требует `npm ci`. Интеграционные проверки запускаются на отдельной временной БД, не на введённых пользователем данных; параметры описаны в `PRESENTATION.md`.

## Контракты и ограничения

API и расчёты описаны в `TRACKING.md`, история — в `HISTORY.md`, запись на приём — в `APPOINTMENTS.md`, разрешения и шифрование — в `SECURITY.md`. При изменении интерфейса сохраняйте реальные API, подтверждённую связь врача с пациентом, согласия, RLS, CSRF, версии и идемпотентность. При изменении схемы добавляйте новую миграцию.

Опросники используют проверенные формулировки и серверный подсчёт. Анализ текста выполняет явно обозначенная локальная заглушка. Доступные функции и незавершённые направления перечислены в `README.md` и `ROADMAP.md`; не заменяйте отсутствующую интеграцию имитацией успеха.

Полный справочник не нужен для запуска и автоматически не загружается. Режимы Docker с восстановлением большого корпуса и старое внешнее демо не относятся к старту этого комплекта. Ключи, пользовательские записи, локальные кластеры и бэкапы не включаются в исходники или новую поставку.
