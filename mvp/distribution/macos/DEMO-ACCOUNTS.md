# Аккаунты этой демонстрационной поставки

Адрес: http://127.0.0.1:4176/ . Аккаунты создаются при первом `START.command`.

| Интерфейс | Логин | Пароль |
|---|---|---|
| Пациент | `patient@compass.example.invalid` | `Compass-Demo-2026!` |
| Врач | `doctor@compass.example.invalid` | `Compass-Demo-2026!` |
| Другой пациент без подключения | `other@compass.example.invalid` | `Compass-Demo-2026!` |

Это общедоступный пароль только для вымышленного локального демонстрационного набора. Не используйте его для настоящих аккаунтов. Адреса не принимают почту. Роль определяется по логину; переключение URL само по себе не даёт прав врача.

Можно открыть два обычных окна или вкладки одного браузера и войти пациентом и врачом: у ролей разные cookie. Для проверки двух разных пациентов используйте отдельный профиль или приватное окно.

Свежие ключи шифрования и пароли самой PostgreSQL генерируются отдельно на каждом компьютере. В этом файле их нет. Файл `qa/presentation/accounts.json` после первого запуска описывает именно созданный локальный экземпляр.
